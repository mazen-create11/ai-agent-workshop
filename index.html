The recipe: four parts

Every agent, small or huge, is built from the same four parts. Tidy uses the simplest version of each.

1

Goal

What you want, in plain English.

GOAL = "Clean up my Downloads folder…"
2

Model

The brain. It reads the goal and decides the next move.

MODEL = "claude-opus-5-5"
3

Tools

The hands. Normal Python functions the model is allowed to ask for.

list_files() · move_file()
4

Loop

Repeat think, act, see until the goal is done.

for round_number in range(1, 16):

    05

    Same loop, any daily task

    Tidy is the training example. For a real daily task you change three things: what starts the agent, its goal and its tools. The loop stays exactly the same.

    An agent is not always a chat

    A fifth part makes an agent useful every day: the trigger, the thing that starts it. A chat message is only one of four.

    Message

    You send it something: a text, a photo of a receipt, a voice note.

    a Telegram bot receives it
    Schedule

    It wakes up on its own, every morning at 8 or every Sunday night.

    cron (Mac, Linux) · Task Scheduler (Windows)
    Event

    Something happens: a new email, a new file, a form is sent.

    check every 5 minutes, or a webhook
    Button

    You click once or type one command, and it does the whole job.

    python agent.py

    The most useful daily agents never chat. They wake up, do the job and leave the result where you already look: a sheet, your calendar, a draft, a notification. No code? n8n, Make and Zapier each have an AI agent block built from the same parts.

    06

    Agent, script or chatbot?

    Not every task needs an agent. Answer four questions before you build anything. Try the examples first, then your own task.

    Examples

    Does it repeat?Every day, every week, every month.

    Does it need judgment?Reading, understanding, choosing, writing.

    Can you give it the tools?Email, calendar, files, web, a sheet, an app with an API.

    Is a mistake easy to undo?A wrong label is easy. A wrong payment is not.

    About Tidy: sorting by file extension is a fixed rule, so a ten-line script could do the same job. We used it because you can watch every step. An agent earns its place when the job needs reading and judgment, for example “put each PDF in the folder of its course”.

    07

    Four rules for a safe agent

    An agent acts on real things. These four choices in the code keep it under control.

    Few tools

    Two tools are enough for this job. Every extra tool is one more way to make a mistake.

    A fence

    The tools only work inside my_downloads. A name with / or .. is refused.

    A stop

    MAX_ROUNDS = 15. If the agent gets stuck, the loop ends anyway.

    A human says yes

    Tidy has no delete tool, so it cannot delete. In general the agent prepares, and a human approves anything that sends, pays or deletes.
